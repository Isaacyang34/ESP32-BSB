# HUB75 全彩 LED 矩陣面板 (P6)

## 1. 硬體規格 (Specifications)
*   **類型**：HUB75 介面全彩 LED 矩陣面板
*   **點距 (Pitch)**：P6 (相鄰兩顆 LED 中心點距離為 6mm)
*   **常見解析度**：64x32 像素 或 64x64 像素
*   **掃描方式**：通常為 1/16 掃 或 1/32 掃
*   **供電要求**：5V 直流電。**注意：LED 面板全亮時耗電量極大（可達數安培），必須使用獨立的 5V 大功率電源供應器（如 5V/10A 以上），絕對不可直接從 ESP32 供電。**

## 2. 專案功能 (Functions)
*   作為羽球計分板的主顯示畫面。
*   左側以紅色字體顯示 A 隊分數，右側以綠色字體顯示 B 隊分數。
*   透過繪製底線或圖示來標示「目前發球方」。

## 3. 接腳定義 (Pinout)
面板背面通常有兩個 HUB75 接口（`DATA IN` 與 `DATA OUT`），ESP32 必須接在 **`DATA IN`**。
標準 HUB75 接口包含以下腳位：

| 腳位名稱 | 功能說明 |
| :--- | :--- |
| **R1, G1, B1** | 上半部 RGB 顏色資料 |
| **R2, G2, B2** | 下半部 RGB 顏色資料 |
| **A, B, C, D, (E)** | 行掃描控制線 (若為 64x64 面板通常需要 E 腳位) |
| **CLK** | 時脈訊號 (Clock) |
| **LAT / STB** | 資料鎖存 (Latch) |
| **OE** | 輸出致能 (Output Enable，低電位有效，用於控制亮度與畫面刷新) |
| **GND** | 必須與 ESP32 和電源供應器共地 |
