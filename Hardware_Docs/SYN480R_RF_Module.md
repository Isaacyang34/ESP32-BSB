# SYN480R 433MHz 無線遙控接收模組

## 1. 硬體規格 (Specifications)
*   **工作頻率**：433.92 MHz
*   **工作電壓**：3.3V ~ 5.5V (建議接 5V，接收距離與感度會明顯優於 3.3V)。
*   **晶片特色**：採用 SYN480R 晶片，屬於 ASK/OOK (幅移鍵控) 超外差接收模組。相比傳統廉價的再生式接收器，抗干擾能力更強、接收距離更遠。
*   **搭配發射器**：專案搭配 **EV1527** 編碼晶片的四鍵 (A/B/C/D) 遙控器使用。

## 2. 專案功能 (Functions)
*   讓場邊的裁判或球員可以在不依賴手機或網路的情況下，直接透過實體遙控器盲按進行「A隊加分」、「B隊加分」、「減分」等控制。
*   支援讀取 EV1527 的**複合鍵**功能（例如同時按下 A+B 鍵會產生專屬代碼，可用來觸發重置分數等特殊功能）。

## 3. 接腳定義 (Pinout)
| SYN480R 腳位 | 連接對象 | 備註 |
| :--- | :--- | :--- |
| **VCC** | 5V 電源 | 建議接 5V 以獲得最佳接收距離 |
| **GND** | 系統 GND | 必須與 ESP32 共地 |
| **DATA / OUT** | ESP32 的 **GPIO 4** | 輸出解碼後的數位訊號。ESP32 端必須使用 `digitalPinToInterrupt` 來精確捕捉微秒級的高低電位變化。 |
| **ANT** | 實體天線 | 務必焊接一條長度約 17.3 公分的銅線，或購買 433MHz 專用彈簧天線，否則接收距離會非常短！ |

## 4. 軟體解碼機制
*   ESP32 端使用 `rc-switch` 函式庫。
*   EV1527 遙控器按下時，會發射一串 24-bit 的資料：
    *   前 20-bit：遙控器的出廠唯一內碼 (ID)。
    *   後 4-bit：按鍵狀態 (Data)。
*   若要測試遙控器每個按鈕的代碼，請使用專案內提供的 `test_433mhz/test_433mhz.ino` 進行擷取。
