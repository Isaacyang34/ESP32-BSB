# CX1000AC (WT2003S) 語音報分模組

## 1. 硬體規格 (Specifications)
*   **支援格式**：支援高音質 MP3、WAV 檔案解碼。
*   **儲存方式**：內建快閃記憶體 (Flash) 或支援 MicroSD 卡擴充。
*   **輸出功能**：內建小型 D類音訊放大器（通常為 2W~3W），可直接推動 4Ω 或 8Ω 的小喇叭，不需外接擴大機。
*   **通訊介面**：UART (標準非同步序列通訊)。
*   **工作電壓**：3.3V ~ 5V (建議使用 5V 以獲得較佳的喇叭推力)。

## 2. 專案功能 (Functions)
*   當計分板分數發生變動，或使用者透過 BLE/遙控器發送指令時，負責大聲報出目前比分。
*   透過 ESP32 內部排隊機制 (Queue)，確保語音會依照「A隊分數 ➜ 比 ➜ B隊分數」的順序不重疊地播放。

## 3. 接腳定義 (Pinout)
| CX1000AC 腳位 | 連接對象 | 備註 |
| :--- | :--- | :--- |
| **VCC** | 5V 電源 | 提供模組與內建擴大機電源 |
| **GND** | 系統 GND | 必須與 ESP32 共地 |
| **RX** | ESP32 的 **GPIO 39** (TX) | 接收來自 ESP32 的播放指令。建議串聯一顆 1KΩ 電阻以消除底噪。 |
| **TX** | ESP32 的 **GPIO 40** (RX) | (非必要) 用於回傳播放結束等狀態給 ESP32。 |
| **SPK+** | 喇叭正極 | 直接推動 3W 小喇叭 |
| **SPK-** | 喇叭負極 | 直接推動 3W 小喇叭 |

## 4. 通訊協定與檔案命名格式
*   **檔案命名**：語音檔需放入模組記憶體中，命名格式為 `00000.mp3` ~ `00031.mp3`。
    *   `00000.mp3`：0 分
    *   `00030.mp3`：30 分
    *   `00031.mp3`：比 (Versus)
*   **控制指令 (Hex)**：採用 9-byte 格式。
    播放指令範例：`0x7E 0x09 0xFF 0xFF 0x07 [High Byte] [Low Byte] [Checksum] 0xEF`
